# Cat SNS App 主要ユーザーフローたたき台

最終更新: 2026-09-01
ステータス: Draft

## 1. 初回利用

1. アプリ起動
2. ログイン / 新規登録
3. Apple / Google / メールアドレスで認証
4. 初回猫登録
5. 猫プロフィール作成
6. ホーム「おすすめ」へ遷移

初回時はフォロー猫が0匹なので「フォロー」タブは表示しない。

## 2. 猫を見つけてフォロー

1. おすすめ投稿を見る
2. 投稿者の猫をタップ
3. 猫プロフィールを開く
4. フォロー
5. フォロー猫が1匹以上になる
6. ホームに「フォロー」タブが表示される

## 3. 画像投稿

1. 投稿ボタン
2. 画像を1〜4枚選択
3. 軽量モデレーション
4. 各画像をALLOW / REJECT / REVIEWへ分類
5. REVIEWのみWorkers AI Visionへ送信
6. すべてALLOWなら編集画面へ
7. 投稿主体の猫を選択
8. 本文 / ハッシュタグ / メンション入力
9. 写っている猫を必要に応じてタグ付け
10. 投稿確定
11. 公開

REJECTが1枚でもある場合:
- 投稿不可
- NG理由を表示
- 該当画像の削除 / 差し替えを促す

## 4. 動画投稿

1. 投稿ボタン
2. 動画1本を選択
3. 30秒上限チェック
4. Cloudflare Streamへアップロード
5. モデレーション用フレーム抽出
6. 各フレームをALLOW / REJECT / REVIEWへ分類
7. REVIEWのみWorkers AI Visionへ送信
8. 全体としてALLOWなら投稿編集へ
9. 投稿主体の猫を選択
10. 本文 / ハッシュタグ / メンション入力
11. 投稿確定
12. 公開

## 5. おすすめ閲覧

1. ホームを開く
2. おすすめ投稿を20件取得
3. スクロール
4. いいね / コメント / 保存 / 外部共有
5. 猫プロフィールへ遷移
6. 必要ならフォロー
7. cursorで次ページ取得

## 6. フォロータイムライン

前提:
- フォロー猫が1匹以上

1. ホームを開く
2. 「フォロー」タブを選択
3. フォロー中の猫の投稿を新着順表示
4. スクロール
5. cursorで次ページ取得

## 7. 複数猫管理

1. 「マイ猫」を開く
2. 管理中の猫一覧を見る
3. 猫追加
4. 猫情報入力
5. 保存
6. 投稿時に投稿主体として選択可能になる

## 8. 検索

1. 検索画面
2. キーワード入力
3. 猫名 / 猫種 / ハッシュタグから検索
4. 結果を選択
5. 猫プロフィールまたはハッシュタグ投稿一覧へ

ユーザー情報は検索対象にしない。

## 9. コメント

1. 投稿詳細
2. コメント表示
3. コメント入力
4. 投稿
5. 投稿管理ユーザーへ通知
6. コメントへの返信も可能

## 10. 通報

1. 投稿または猫プロフィールのメニューを開く
2. 「通報」
3. 通報理由を選択
4. 任意詳細を入力
5. 送信
6. reportsへ保存
7. 運営管理画面から確認

## 11. ブロック

ユーザー情報は公開しないが、内部的なユーザー主体に対してブロックする。

1. 対象コンテンツのメニューからブロック
2. 内部ユーザーIDをブロック
3. 相手が管理する猫 / 投稿 / コメントを原則非表示
4. 相手からのインタラクションも制限

詳細な適用範囲は実装前に確定する。

## 12. アカウント削除

1. 設定
2. アカウント削除
3. 注意事項表示
4. 再認証
5. 削除実行
6. 管理猫 / 投稿の扱いを削除ポリシーに従って処理

## 13. エラー系フロー

### モデレーション失敗
- 一時エラーなら再判定
- 判定不能なら投稿確定不可

### Streamアップロード失敗
- リトライ
- 未完了投稿はdraft扱い

### API失敗
- 楽観更新を戻す
- 再試行UI

## 14. MVPで特に重視する体験

- 初回登録後すぐ猫投稿を見られる
- 猫がSNS上の主役として見える
- 投稿時の画像判定が煩雑に感じない
- 猫をフォローするとホームUIが自然に変化する
- 飼い主ユーザー情報を意識せず利用できる
