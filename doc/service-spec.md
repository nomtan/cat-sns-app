# Cat SNS App 仕様書

最終更新: 2026-09-01

## 1. サービス概要

猫の画像のみ投稿できるSNS。

一般的なSNSのアカウント単位の投稿に加え、1人のユーザーが複数匹の猫を登録し、それぞれの猫ごとに独立したマイページと投稿履歴を持てることを特徴とする。

## 2. 対応プラットフォーム

- Web
- iOS
- Android

## 3. フロントエンド / アプリ技術

### Web
- React系で構築予定
- UIはXまたはInstagramの体験をベースに設計する

### iOS / Android
- React Native
- UI Kit: HeroUI

## 4. バックエンド

- Cloudflareを利用する
- 詳細構成（Workers / D1 / R2 / KV / Queues 等）は今後決定する

## 5. 投稿仕様

- 投稿できる画像は猫の画像のみ
- 投稿時に画像認識モデルまたは画像認識系プラグイン / APIを利用して猫画像かどうかを判定する
- 猫以外の画像は投稿不可とする
- 画像判定の具体的なモデル・サービス・判定閾値・例外処理は今後決定する

## 6. ユーザーと猫プロフィール

### ユーザー
- 1ユーザーにつき1つのユーザーアカウントを持つ
- 1ユーザーは複数匹の猫を登録できる

### 猫プロフィール
- 各猫は独立したプロフィールページ（猫用マイページ）を持つ
- 投稿時に、どの猫の投稿なのかを紐付けられる
- 猫ごとに投稿一覧を表示できる

## 7. UI / UX方針

- XまたはInstagramのUI/UXを参考にする
- SNSとして馴染みのある操作感を優先する
- 猫プロフィールを「もう1つのアカウント」のように扱える体験を差別化ポイントとする
