# Cat SNS App 画面一覧たたき台

最終更新: 2026-09-01
ステータス: Draft

## 1. 認証 / 初回導線

### 1.1 スプラッシュ
- ロゴ
- セッション確認

### 1.2 ログイン / 新規登録
- Apple
- Google
- メールアドレス

### 1.3 初回猫登録
- 猫の名前
- アイコン
- 性別
- 誕生日
- 猫種
- 毛色
- 登録完了

## 2. メインナビゲーション

Mobileの下部タブ候補:
- ホーム
- 検索
- 投稿
- 通知
- マイ猫

Webでは左サイドナビゲーションまたは上部ナビゲーションへ展開する。

## 3. ホーム

### 3.1 おすすめ
- おすすめ投稿一覧
- 画像 / 動画
- 猫名
- 猫アイコン
- いいね
- コメント
- 保存
- 外部共有
- フォロー導線

### 3.2 フォロー
- フォロー中の猫の投稿を時系列表示
- フォロー猫が0匹の場合はタブ自体を表示しない

## 4. 投稿

### 4.1 メディア選択
- 画像 1〜4枚
- または動画 1本
- 画像と動画の混在不可

### 4.2 投稿編集
- 投稿主体の猫選択
- 本文
- ハッシュタグ
- メンション
- 写っている猫のタグ付け

### 4.3 モデレーション
- 判定中
- ALLOW
- REJECT
- REVIEW
- REVIEW時はWorkers AI Vision判定中表示
- NG理由表示
- 問題画像 / 動画の差し替え

### 4.4 投稿完了
- 投稿詳細へ遷移

## 5. 投稿詳細

- 投稿メディア
- 投稿猫
- 本文
- ハッシュタグ
- タグ付け猫
- いいね数
- コメント
- 保存
- 外部共有
- 通報

## 6. 猫プロフィール

- 猫アイコン
- 名前
- 性別
- 誕生日
- 猫種
- 毛色
- フォロワー数
- フォローボタン
- 投稿一覧

ユーザー / 飼い主情報は表示しない。

## 7. マイ猫

### 7.1 マイ猫一覧
- 自分が管理する猫一覧
- 猫追加
- 猫編集
- 投稿数等

### 7.2 猫登録
- 名前
- アイコン
- 性別
- 誕生日
- 猫種
- 毛色

### 7.3 猫編集
- 登録項目編集
- 削除

## 8. 検索

検索対象:
- 猫の名前
- 猫種
- ハッシュタグ

### 8.1 検索トップ
- 検索フォーム
- 注目ハッシュタグ候補
- おすすめ猫候補

### 8.2 検索結果
タブ候補:
- 猫
- 猫種
- ハッシュタグ

## 9. 通知

- 保存投稿一覧

## 12. 設定

- アカウント
- ログアウト
- ブロック管理
- ミュート管理
- 利用規約
- プライバシーポリシー
- お問い合わせ
- アカウント削除

## 13. 通報

対象:
- 投稿
- 猫プロフィール
- ユーザー内部主体（公開情報は表示しない）

通報理由候補:
- 猫が写っていない
- イラスト / AI画像
- 虐待 / 暴力
- 不適切な内容
- スパム
- その他

## 14. 管理画面

運営向けWeb管理画面。

- 通報一覧
- 投稿確認
- 猫プロフィール確認
- ユーザー内部情報確認
- モデレーション結果確認
- 投稿削除 / 復旧
- アカウント停止
- モデレーション閾値確認
